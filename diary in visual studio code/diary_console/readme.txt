the ".vscode" folder is for compiling & running c/c++ files with MSVC
press F5 or click "Run C/C++ File"

compile Diary.c with GCC
gcc -std=c17 -Wall -Wextra Diary.c -o Diary

run application
.\Diary OR Diary.exe

compile encryption_code.c with GCC
gcc -std=c17 -Wall -Wextra encryption_code.c -o encryption_code

run application
.\encryption_code OR encryption_code.exe
